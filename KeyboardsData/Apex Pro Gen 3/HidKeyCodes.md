# HID Key Code Reference

This table lists common keyboard keys and their USB HID Usage Codes as defined by the [USB HID Usage Tables specification](https://usb.org/sites/default/files/hut1_5.pdf) (Usage Page 0x07 — Keyboard/Keypad).

HID codes are represented as 8-bit unsigned integers (0x00–0xFF).
